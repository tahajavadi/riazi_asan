# ریاضیِ آسان — پروژهٔ APK اندروید

فایل HTML در `app/src/main/assets/index.html` داخل برنامه بسته‌بندی شده و کاربر لازم نیست آن را انتخاب کند. برنامه بدون اینترنت و با WebView اجرا می‌شود.

## ساخت APK با GitHub Actions
1. یک مخزن جدید در GitHub بساز.
2. همهٔ محتویات این پوشه را در مخزن بارگذاری کن.
3. از زبانهٔ Actions، گردش کار `Build Riazi Asan APK` را اجرا کن.
4. پس از پایان موفق، از بخش Artifacts فایل `RiaziAsan-debug-apk` را دریافت کن؛ داخل آن `app-debug.apk` است.

این خروجی نسخهٔ آزمایشی (debug) است. مبهم‌سازی HTML به‌تنهایی تضمین نمی‌کند کسی نتواند آن را استخراج یا تغییر دهد؛ این پروژه فایل را داخل APK قرار می‌دهد و ویرایش مستقیم فایل جداگانه را حذف می‌کند.
